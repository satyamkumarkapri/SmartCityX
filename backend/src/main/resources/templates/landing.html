About SmartCityX

SmartCityX is an advanced urban management platform built to monitor, analyze, and optimize city infrastructure in real-time. Created for a modern connected world, this platform integrates various urban systems into a single, cohesive dashboard.

Algorithm Workbench

Utilizes complex data structures and algorithms (Dijkstra's, Aho-Corasick, DP) for traffic routing, pattern matching, and resource optimization.

Cloud-Native Architecture

Powered by Java Spring Boot and securely connected to a serverless PostgreSQL database (Neon) for highly available, real-time data streaming.

Premium UI/UX

Designed with glassmorphism, fluid micro-interactions, and a responsive layout that provides operators with a crystal-clear view of the city's heartbeat.
