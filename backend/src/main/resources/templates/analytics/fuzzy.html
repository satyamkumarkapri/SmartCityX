Levenshtein Distance

Computes the minimum number of single-character edits (insert, delete, substitute) required to transform string A into string B. Used to correct citizen query typos.

How Edit Distance Works
Levenshtein Distance

dp[i][j] = min of:
• dp[i-1][j] + 1 (deletion)
• dp[i][j-1] + 1 (insertion)
• dp[i-1][j-1] + cost (substitution, cost=0 if equal)

Time: O(mn) | Space: O(mn)

Damerau-Levenshtein Distance

Extends Levenshtein by also allowing:
• Transposition of adjacent characters (ab → ba)

This handles common typographical errors more accurately. Used in natural language processing and spell correction systems.
