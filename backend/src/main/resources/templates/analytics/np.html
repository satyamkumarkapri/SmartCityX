Vertex Cover (2-Approximation)

A vertex cover is a set S of vertices such that every edge has at least one endpoint in S. Minimum Vertex Cover is NP-Complete; the 2-Approximation runs in O(E). City context: Minimum set of intersections to monitor for full traffic coverage.

Maximum Clique

A clique is a subset of vertices where every pair is connected. Max Clique is NP-Complete (3-SAT reduces to Clique). City context: Find maximum group of zones with mutual emergency communication links.

Maximum Independent Set

An independent set is a subset of vertices with no edges between them. Complement of a Clique. NP-Complete. City context: Maximum set of non-adjacent traffic monitoring nodes.

NP-Complete Reduction Chain

3-SAT → CLIQUE

For a 3-SAT formula with k clauses, create a graph with k groups of vertices (one per clause). Connect u,v if they are in different clauses and the literals are not complementary. The formula is satisfiable iff there's a k-clique.

CLIQUE → INDEPENDENT SET

S is a k-clique in G iff S is a k-independent set in the complement graph G̅. Simply negate all edges: edges become non-edges and vice versa.

INDEPENDENT SET → VERTEX COVER

S is an independent set iff V \ S is a vertex cover. The vertex cover consists of all nodes NOT in the independent set.

2-Approximation for Vertex Cover

Greedily pick maximal matchings and include both endpoints. Guaranteed to be at most 2× optimal. OPT ≤ ALG ≤ 2 × OPT.
