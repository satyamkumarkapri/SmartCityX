About Bipartite Matching

In SmartCityX, bipartite matching assigns limited city resources to service requests optimally. The left set represents available units (ambulances, tankers, etc.) and the right set represents active incidents. The algorithm finds the maximum number of assignments where each resource handles exactly one incident and each incident is handled by at most one resource.
