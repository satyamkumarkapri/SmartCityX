Knuth-Morris-Pratt (KMP)

Searches for pattern in text in O(n+m) using a Longest Proper Prefix-Suffix (LPS) array to skip redundant comparisons. Used in SmartCityX to search citizen reports and service request descriptions.

Z-Function Algorithm

Z[i] = longest substring starting at position i that is also a prefix of the string. O(n+m) time. Used to identify repeated patterns in city reports.

Rabin-Karp Rolling Hash

Uses polynomial rolling hash to match patterns. Average O(n+m). Shows hash values and spurious hits. Used to search service and infrastructure identifiers.

Aho-Corasick Multi-Pattern

Builds a finite automaton to search multiple keywords simultaneously in O(n + total_pattern_length + matches). Used to detect multiple emergency and service keywords.
